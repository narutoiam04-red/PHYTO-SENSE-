NCSC RESEARCH PROJECT — LIVE MONITORING PROTOTYPE

PHYTO-SENSE ∞

A multimodal living-sensor network for non-destructive detection and recovery monitoring of plant nutrient stress.

Can measurements from living plants, combined with environmental sensors, detect experimentally induced nutrient stress — and track recovery after nutrient restoration is applied?

02 — Sensing Layer

What each node measures

Per-plant: an ESP32 reads soil moisture and a DS18B20 probe. Shared across the array: a BME280 for air temperature and humidity, a BH1750 for light intensity, an MLX90614 for non-contact leaf-surface temperature, and a camera for leaf area, colour, and growth morphology.

04 — Protocol

Four phases, in order

PHASE 1
Baseline
All three plants receive identical, normal conditions. Establishes what "normal" looks like across every sensor channel.
PHASE 2
Controlled condition
Nutrient-limitation is introduced mildly, under supervision, to P2 and P3. Measurement continues without interruption.
PHASE 3
Restoration
Experimental plants return to appropriate nutrition. Recovery is measured, never assumed.
PHASE 4
Recovery
Growth, leaf measurements, temperature, moisture and image features are tracked against baseline and control.

09 — Rigor

Controls & uncertainty

same species, same starting plant size
same pot type, same growing medium
same light exposure, same measurement time
same watering and sensor procedure
same camera position for every image
P1 as reference for normal variation

Precision is reported at the level the sensor actually supports — mean, standard deviation, measurement error, percentage change, and confidence intervals where appropriate. Not false digits.
